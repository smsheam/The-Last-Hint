# DEAD SIGNAL: শেষ সংকেত

A Bengali, mobile-first social deduction thriller game. Set in a fictional near-future Dhaka during a citywide communication blackout.

## Modes
- **গল্প মোড (Story Mode):** A narrative case file with a local thriller setting.
- **কুইক ম্যাচ (Quick Mode):** Pass-and-play hidden-role match for 5–8 players.
- **ফান মোড (Fun Mode):** Humorous events and chaotic Bangla announcements.

## Run
Open `index.html` in a browser, or enable GitHub Pages from repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Current build
- Responsive mobile UI
- Bengali interface and Bangladeshi setting
- Hidden role reveal, private pass-and-play flow
- Action, investigation, voting and role reveal phases
- Local browser gameplay; no account or server required

## Note
This is an early playable prototype. Multiplayer across separate devices, online rooms, persistent story chapters, and full server-authoritative anti-cheat are not implemented yet.
